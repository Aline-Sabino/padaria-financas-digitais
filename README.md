# 📌 Padaria e Finanças Digitais

## 📖 Sobre o projeto

Projeto acadêmico para modelagem de um sistema de banco de dados voltado à gestão de uma padaria.

O sistema contempla fornecedores, produtos, estoque e vendas, e será expandido para incluir finanças digitais (contas a pagar, contas a receber e fluxo de caixa).

## 🗂 Estrutura atual

### Tabelas já implementadas:

- `fornecedores`
- `produtos`
- `estoque`
- `vendas`
- `itens_da_venda`

## ⚙️ Como usar

O banco de dados é desenvolvido utilizando MariaDB.

O arquivo `padaria.sql` contém o script para criação das tabelas.
